# Електронні таблиці — Лабораторна робота №1, варіант 46

**Автор:** Іхонкіна Уляна, група К-26
**Рівень:** середній

Програма для роботи з електронними таблицями (аналіз та обчислення виразів).
C#, .NET 10, інтерфейс — .NET MAUI (Windows), розбір виразів — ANTLR 4.

## Варіант 46

Набори операцій 1, 4, 7, 8, 9:

| Набір | Операції |
|---|---|
| 1 | `+  -  *  /` (бінарні) |
| 4 | `^` (піднесення до степеня) |
| 7 | `mmax(x1, …, xN)`, `mmin(x1, …, xN)`, N ≥ 1 |
| 8 | `=  <  >` |
| 9 | `<=  >=  <>` |

Вираз у клітинці **логічний** (результат — ІСТИНА / ХИБНІСТЬ).
У виразах: цілі числа довільної довжини, круглі дужки, імена клітинок (`A3`).

## Можливості

- введення та редагування виразів у клітинках;
- збереження таблиці у файл (JSON) і відкриття з файлу;
- додавання та видалення рядків і стовпців (з попередженням, якщо є дані або посилання на клітинки, що видаляються);
- два етапи обробки виразу:
  1. синтаксична перевірка з локалізацією помилки (повідомлення українською + номер символу);
  2. обчислення значення;
- режими відображення **ВИРАЗ / ЗНАЧЕННЯ**;
- автоматичний перерахунок клітинок, що посилаються на змінену;
- виявлення циклічних посилань, ділення на нуль, посилань на неіснуючі клітинки;
- довідка, інформація про програму, пропозиція зберегти зміни перед виходом.

## Приклади виразів

```
=5 > 3                      → ІСТИНА
=(2 + 3) * 4 = 20           → ІСТИНА
=2 ^ 3 ^ 2 = 512            → ІСТИНА
=mmax(A1, 5) >= 10          → ХИБНІСТЬ
=1 + * 2 > 0                → синтаксична помилка, позиція 6
=10 / 0 > 1                 → помилка обчислення: ділення на нуль
```

## Граматика (ANTLR)

Файл `SpreadsheetLab.Core/Grammar/LabCalculator.g4`, правила парсера:

```antlr
compileUnit : EQUAL? expression EOF ;

expression
    : LPAREN expression RPAREN                                         #ParenthesizedExpr
    | <assoc=right> expression EXPONENT expression                     #ExponentialExpr
    | expression operatorToken=(MULTIPLY | DIVIDE) expression          #MultiplicativeExpr
    | expression operatorToken=(ADD | SUBTRACT) expression             #AdditiveExpr
    | expression operatorToken=(EQUAL | NOT_EQUAL | LESS | GREATER | LESS_EQUAL | GREATER_EQUAL) expression   #ComparisonExpr
    | functionName=(MMAX | MMIN) LPAREN arguments+=expression (COMMA arguments+=expression)* RPAREN        #FunctionExpr
    | NUMBER                                                           #NumberExpr
    | IDENTIFIER                                                       #IdentifierExpr
    ;
```

Пріоритет операцій (від вищого до нижчого): `^` → `* /` → `+ -` → порівняння.
Після розбору перевіряється, що головна операція — порівняння (вираз логічний).
У арифметиці значення клітинки: ІСТИНА = 1, ХИБНІСТЬ = 0, порожня клітинка = 0.

## Структура

```
SpreadsheetLab.slnx
├── SpreadsheetLab.App      — інтерфейс (.NET MAUI): MainPage, HelpPage
└── SpreadsheetLab.Core     — уся логіка, без залежності від інтерфейсу
    ├── Models/       Cell, CellAddress, Spreadsheet
    ├── Grammar/      LabCalculator.g4
    ├── Parsing/      ExpressionParser, ThrowExceptionErrorListener
    ├── Evaluation/   LabCalculatorVisitor, Calculator
    └── Services/     FileService
```

| Клас | Призначення |
|---|---|
| `Cell` | клітинка: вираз, значення, помилка; текст для режимів ВИРАЗ / ЗНАЧЕННЯ |
| `CellAddress` | перетворення імен клітинок: "B3" ↔ рядок 2, стовпець 1 |
| `Spreadsheet` | таблиця клітинок, зміна розміру, перевірки перед видаленням |
| `ExpressionParser` | етап 1: лексер і парсер ANTLR → дерево розбору або помилка з позицією |
| `ThrowExceptionErrorListener` | перетворює помилки ANTLR на повідомлення українською |
| `LabCalculatorVisitor` | етап 2: візитор, обчислює дерево (`BigInteger`) |
| `Calculator` | перераховує таблицю, рахує спершу клітинки, на які посилається вираз, знаходить цикли |
| `FileService` | збереження / відкриття JSON, ознака незбережених змін |
| `MainPage` | головне вікно: сітка клітинок, рядок виразу, кнопки, рядок стану |
| `HelpPage` | довідка для користувача |

Обробники кнопок у `MainPage` лише викликають методи `Spreadsheet` і `FileService`,
тому антишаблону «магічна кнопка» немає.

## Відмінності від UML-діаграм
Код дещо відрізняється від UML-діаграм, адже під час роботи я змінювала деякі рішення.

Що змінилось:
- Розбір виразів виконує ANTLR (як рекомендовано в курсі) замість власного класу `Parser`,
  тому класи вузлів дерева (`ExpressionNode` і нащадки) генерує ANTLR.
- `Evaluator` реалізовано як візитор `LabCalculatorVisitor` (шаблон Visitor).
- Замість окремого `DependencyGraph` після кожної зміни перераховується вся таблиця;
  циклічні посилання знаходить `Calculator`.
- Видаляється лише останній рядок / стовпець, тому `RemoveRow()` і `RemoveColumn()` без параметра.
- Додано класи `CellAddress`, `ThrowExceptionErrorListener`, `HelpPage`.

2. Розмістіть проєкт у папці **без кирилиці та пробілів у шляху, будь ласка** —
   інструмент ANTLR не працює з кирилицею в шляху.

   Під час першого збирання потрібен інтернет (завантажуються пакети NuGet та інструмент ANTLR).

##Зміни після зауважень викладача:
1. Ім'я клітинки без порівняння (`=A1`, `=(A1)`) тепер вважається логічним виразом:
   клітинки містять логічні значення, тому `=A1` має те саме значення, що й A1.
2. Відкриття та збереження файлу — через вікно провідника замість введення шляху вручну.
   «Зберегти» записує в поточний файл (для нової таблиці відкриває вікно), «Зберегти як…» завжди відкриває вікно.
3. Від'ємний степінь обчислюється: `a ^ -n = 1 / a ^ n` (ділення ціле, як і для `/`).
   Щоб його можна було записати як `2 ^ -1`, додано унарний мінус (`-5`, `-A1`, `-(A1 + 2)`).
